# Routing

| Request | References to load |
| --- | --- |
| Explain this Python repository | [Understanding](repository-understanding.md) |
| Explain a feature path | Understanding, [feature tracing (draft)](feature-tracing.md) |
| Review what a proposed edit affects | [Change impact (draft)](change-impact.md), relevant feature context |
| Diagnose a crash | Understanding, [reproduction](bug-reproduction.md) |
| Repair a demonstrated bug | Understanding, reproduction, [implementation](implementation.md), [verification](regression-testing.md) |
| Check an existing fix | Verification and relevant implementation context |
| Review a public response/interface change | [API compatibility (draft)](api-compatibility.md), change impact |
| Diagnose installation or upgrade failure | [Dependency diagnosis (draft)](dependency-diagnosis.md), reproduction and verification as relevant |

Do not run every workflow for a small task. Database, security, performance, documentation-verification and delivery workflows remain planned. Use the agent's available expertise when appropriate and state this package's scope honestly.
