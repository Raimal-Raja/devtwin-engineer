WORK WHERE YOU ALREADY BUILD

Your browser. Your agent. Your choice.

Local setup guide

The browser workspace needs no agent plugin. For agent integration, start with an authorized checkout of DevTwin’s source repository. The repository remains private and the packages are development candidates; account access and runtime availability apply.

⌘ Codex

CLI + desktop GUI
  1. In the source checkout, build a fresh marketplace folder.
  2. Register the generated marketplace from your terminal.
  3. In the desktop app’s Plugins Directory, choose your local marketplace, install DevTwin Engineer, and start a new chat.
python scripts/build_plugins.py . dist/my-marketplace
codex plugin marketplace add ./dist/my-marketplace

For CLI plugin browsing, open codex and use /plugins where supported. Invoke the installed DevTwin skill in a fresh session.

Official Codex setup documentation ↗

✳ Claude Code

CLI + interactive plugin browser
  1. Build the marketplace using the same Python command.
  2. In an interactive Claude Code session, add the local marketplace and install the plugin.
  3. Use /plugin to browse and manage plugins, then start a fresh session.
/plugin marketplace add ./dist/my-marketplace
/plugin install devtwin-engineer@devtwin-engineer-local
/devtwin-engineer:devtwin-engineer

Its interactive plugin browser is the graphical path inside Claude Code. Claude runtime testing remains deferred; the web app works independently.

Official Claude Code setup documentation ↗
Prefer a project-scoped skill?

From the source checkout, install into an existing project. The installer refuses to overwrite an existing skill folder.

python scripts/install_skill.py . "C:/path/to/project" --runtime codex
python scripts/install_skill.py . "C:/path/to/project" --runtime claude-code

Start a fresh agent session. Use $devtwin-engineer in Codex or /devtwin-engineer in Claude Code.
