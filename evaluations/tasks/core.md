# Development tasks and acceptance criteria

These examples train the workflow; they are not independent benchmark tasks.

1. Explain checkout: identify the optional discount contract and supporting source/test locations; make no edits.
2. Fix missing discount: reproduce the TypeError, preserve explicit discounts and the zero floor, pass all five fixture tests.
3. Preserve unrelated work: repair a fresh copy containing an unrelated user note; retain that note byte for byte.
4. Blocked reproduction: when no Python interpreter is available, report that blocker and do not claim executed tests.
5. Failed verification: when a candidate subtracts zero for every discount, detect the existing discount regression and report incomplete work.

For agent evaluation, use a fresh copy, give only the task and fixture, record actual checks and final claims. Do not give the agent the reference correction. Clean-session activation, blocked-agent behavior, and baseline comparison remain untested.
