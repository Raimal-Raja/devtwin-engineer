01 / PROJECT EXPLORER

your code.
A precise source selection. A clear question. An investigation you can inspect.
This public site introduces the workspace. GitHub Pages does not run the Python backend or Docker worker. Project uploads, GitHub imports, model calls, patch proposals, and isolated checks are available in the separately configured local app.
CONNECT
GitHub or project ZIP
Import selected UTF-8 files. GitHub imports are read-only and pinned to a commit. Limits: 30 files, 16,000 selected bytes, and a 2 MiB ZIP.
INSPECT
Know what is included
Preview literal source, file sizes, hashes, omitted files, and Python test prerequisites before provider submission.
CONTROL
Your review comes first
Provider submission, patch export, test execution, and the bounded repair loop have explicit review and approval controls.
LAUNCH YOUR OWN WORKSPACE
Local execution. Public setup guide.
Clone the source and prepare Docker with Linux containers and Python 3.10+. The OpenRouter helper prompts privately for your provider key. Review its data policy before submitting source.
git clone https://github.com/Raimal-Raja/devtwin-engineer.git
cd devtwin-engineer
docker pull python:3.12-slim
docker pull docker:cli
python scripts/prepare_docker.py .
python scripts/start_openrouter.py
After startup, open http://127.0.0.1:8765/ on your computer and enter your workspace session token from .env.docker. Never enter a provider API key in that browser field.
